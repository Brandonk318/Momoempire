# Mind At Ease Solutions

This repository holds the product code and specs for **Mind At Ease Solutions**:

- **Bookkeeping app** for self-employed contractors (HVAC, roofing, plumbing, electrical, landscaping).
- **Contractor Academy**: a free educational layer (15 short video modules plus voice quizzes) teaching contractors how to run their business.
- **Referral program**: 25% payouts for current customers who refer paying customers, with chargeback/refund protections.

"Momoempire" is the internal repository name only. Public-facing copy uses the Mind At Ease Solutions brand.

## Docs

- [Contractor Academy spec](docs/contractor-academy-spec.md): curriculum, voice style, visuals, audio, quizzes, pricing, referral, and chargeback rules.

## Layout

- `backend/`: API server
- `frontend/`: web app
- `tests/`: test suite
